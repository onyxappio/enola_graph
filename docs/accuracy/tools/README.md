# Accuracy report highlighting

Run `pnpm install`, then `node twinkleplop-report.mjs input.html output.html`.
Uses local Chrome via Playwright; embeds GitHub dark CSS and verifies exact code
text, no external assets and no mobile overflow. TypeScript/JavaScript, HTML and
Markdown use Twinkleplop. Swift stays plain text (no available Swift grammar).
Output is standalone; viewing requires no dependencies.
